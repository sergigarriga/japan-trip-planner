# Seguridad

Esta guía no tiene servidor ni cuentas: todo lo que añade el usuario se guarda en su navegador. Aun así, si encuentras una vulnerabilidad (por ejemplo, una forma de inyectar código a través de los textos editables), por favor **no abras un issue público**.

Usa el aviso privado de GitHub: pestaña **Security → Report a vulnerability** de este repositorio. Responderé en cuanto pueda y publicaré la corrección con mención a tu aviso, si quieres.

Se da soporte a la última versión publicada.
